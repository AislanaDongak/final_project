# Терра · Городской ботанический сад — брендбук

Дружелюбный и современный брендбук ботанического сада «Терра».
Сад — место для семейного отдыха и образовательных программ: играем, учимся, отдыхаем.

Стек: HTML / CSS / JavaScript, без внешних зависимостей.
Публикация: ветка `main` → GitHub Pages / GitVerse Pages.

## Правила работы с ветками

- `main` **защищена**: прямой push, force push и удаление запрещены.
- Любое изменение попадает в `main` **только через PR/MR** после одобрения (минимум 1 approve).
- Схема: личная ветка → локальная проверка → PR/MR + ревью → merge в `main` → проверка сайта по публичной ссылке.
- Перед началом задачи обновляемся:
  ```bash
  git switch main
  git pull --ff-only origin main
  git switch -c feature/<имя>-<зона>
