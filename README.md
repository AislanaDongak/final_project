# ТЕРРА — командный интерактивный брендбук

Тема №15: городской ботанический сад — афиша экскурсии и карточка растения.

## Команда и владение файлами

| Участник | Ветка | Файлы |
|---|---|---|
| Лидер | `feature/home` | `index.html`, `js/home.js` |
| Участник 2 (Алина) | `feature/colors` | `colors.html`, `js/colors.js` |
| Участник 3 | `feature/studio` | `studio.html`, `js/studio.js` |

Общие файлы принадлежат исходному каркасу в `main`: `css/site.css`, `js/state.js`, `assets/*.svg`. Они уже содержат стили и ресурсы для всех трёх страниц. Изменять общие файлы — только по согласованию и через отдельный PR.

## Запуск

Откройте **корень** репозитория в VS Code и запускайте `index.html` через Live Server (Go Live) или используйте GitHub Pages. Не открывайте через `file://`, так как используются ES-модули.

После слияния всех трёх PR получатся три страницы: `index.html` → `colors.html` → `studio.html`, со ссылками обратно на соседние страницы. Пути относительные, все HTML-файлы лежат в корне.

**Важно:** до слияния соответствующего PR переход на ещё не загруженную страницу будет выдавать 404. Это нормально на промежуточной стадии и исчезнет после слияния всех трёх веток.

## Общий договор по состоянию

- Модуль: `./js/state.js` (импорт со страниц через их собственные JS-модули).
- Ключ `localStorage`: `terra-brandbook-v1`.
- Методы: `getState()`, `patch({ ... })`, `reset()`, `subscribe(cb)`.
- Поля: `name`, `slogan`, `paletteId`, `posterPaletteId`, `season`, `font`, `fontSize`, `weight`, `layout`, `plant`, `route`.
- Палитра основной страницы и студии остаётся базовой зелёной. `paletteId` переключает только лабораторию цвета; `posterPaletteId` управляет афишей и гербарием в студии.

## Проверка после слияния

1. Открыть `index.html`, изменить имя и слоган и перейти на `studio.html`; оба макета должны обновиться.
2. Открыть `colors.html`, проверить полный поворот цветка и смену трёх палитр; перейти на главную — фон должен быть базовым зелёным.
3. Проверить все четыре сезона и фотографии (нужен интернет).
4. В `studio.html` выбрать ирис, поменять цвет афиши, шрифт, насыщенность, композицию и билет.
5. Обновить страницу: настройки должны сохраниться. Сбросить их и проверить печать/PDF.
6. Проверить на телефоне и с клавиатуры.

## Источники и ограничения

Растительные SVG-иллюстрации включены локально. Веб-шрифты Yeseva One и Unbounded подключаются через Google Fonts. Фотографии сезонных сцен с Pexels указаны с авторскими подписями в самом сайте. Для внешних ресурсов нужен интернет. Код и дизайн учебного макета созданы с помощью ИИ, проверка JavaScript необходима перед сдачей.
